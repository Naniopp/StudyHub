# Manual verification checklist

- Register with valid details; reject mismatched/weak password and duplicate email.
- Sign out, log in with correct credentials, reject incorrect credentials, refresh a protected page, and verify the session persists.
- Create/edit/complete/reopen/delete a task; refresh and confirm persistence. Search and filter it. Check an overdue date.
- Switch Light, Dark, System in header and Settings; refresh and verify preference.
- Generate a quiz with a configured provider key. Check question count and settings; refresh the active quiz and confirm selected answers restore in that tab.
- Submit with some unanswered questions. Confirm score and answer key appear only after submission; try submitting again.
- Visit results from history; verify chart and subject summaries update.
- Use a second account and confirm task/history records are isolated.
- At mobile width, exercise menu, task modal, quiz answers and navigation without horizontal overflow.
- Remove AI key and confirm generation returns an explicit configuration error while preserving the selected form values.
